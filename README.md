# glp1-trial-watch-4

Tracking repository for GLP-1 receptor agonist trials in type 2 diabetes — late-stage landscape monitoring for the endocrinology group's quarterly pipeline review.

## What this repo is for

This repository captures the current late-stage (recruiting) landscape of GLP-1 receptor agonist studies in adults with type 2 diabetes, as surfaced on ClinicalTrials.gov. It holds:

- **Tracking issues** — one per selected late-stage trial, with sponsor, phase, planned enrollment, and primary completion date.
- **A parent summary issue** — an overview of the landscape with phase and sponsor-class breakdowns.

## Theme

This quarter's pipeline review theme: GLP-1 receptor agonists in type 2 diabetes.
